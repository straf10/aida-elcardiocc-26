<h1 align="center">ELCardioCC</h1>

## Τι κάνουμε

Στο **ELCardioCC** (shared task BioASQ / CLEF) χτίζουμε σύστημα που παίρνει **ελληνικό κείμενο εξιτηρίου καρδιολογίας** και προβλέπει **κωδικούς ICD-10** (πολυ-ετικέτα) — δηλαδή ποιες διαγνώσεις και κλινικές καταστάσεις καλύπτει το έγγραφο.

## Ποιοι είμαστε

Μεταπτυχιακοί φοιτητές στο πρόγραμμα **AIDA** — *AI and Data Analytics* — του [**Πανεπιστημίου Μακεδονίας**](https://www.uom.gr) (*University of Macedonia*).
